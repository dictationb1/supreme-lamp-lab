# Smart Dictation Player v2.6.0 (ver 18) — release report

Date: 2026-10-24 · App: `dictationb1/dictationb1.github.io` · Lab: `dictationb1/supreme-lamp-lab`

## Outcome

The v18 upgrade is **complete and verified** in the sandbox but **not published**:
the Arena GitHub integration is read-only on the app repository, so the release
commit `42bf5d8` (based on app `main` `4fcd9d5`) cannot be pushed and no PR can be
opened there. Everything needed to publish is bundled in
[`releases/2026-10-24-v2.6.0/`](../../releases/2026-10-24-v2.6.0/README.md)
(`0001-release-v2.6.0.patch`, `v2.6.0.diff`, `apply-release.sh`, and a full copy
of the seven changed app files).

## Gates (run twice: in the working clone and on a fresh clone + patch)

```
node tests/check.cjs        PASS   node --check PASS · ES5 PASS · 441,328 / 450,000 bytes
node tests/upgrade.test.cjs 28/28  (rewritten from scratch with fs.writeFileSync)
node tests/phase1.cjs       68/68
node tests/server.cjs       7/7
node tests/upgrade-browser.cjs  SKIP (no runnable browser in this sandbox)
```

`index.html` is **441,328 bytes** — 672 bytes inside the 442,000 target and 8,672
inside the hard ceiling. The 14 KB of new v18 UI was paid for by trimming
duplicate legacy content: per-word audio URLs in `SAMPLE_WORDS` (re-derived by
`ukMp3()`), the re-indented `gas-source` block, dead `.bubble-*` / `.hr` /
`.stepper` CSS, superseded v13/v16 CSS commentary, redundant HTML section
dividers, and `\uXXXX` escapes rewritten as UTF-8.

To publish, run `releases/2026-10-24-v2.6.0/apply-release.sh` from a machine with
write access (it clones, applies the mailbox patch, installs the test
dependencies, re-runs every gate and only then pushes to `main`).

## Notes / follow-ups

* `config/app-source.json` still pins app `978a837` for the staging pipeline on
  purpose: `42bf5d8` does not exist on the app origin, so pinning to it would make
  `Stage-F60UiBundle` refuse every staging run. Update that pin in the same
  commit that publishes v2.6.0.

  not be executed here; run it with Chromium/WebKit before signing off the visual
  layer.

  untouched.
