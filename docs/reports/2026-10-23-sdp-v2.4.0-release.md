## Verdict

The release is **built and verified** in the sandbox and is **not published**: the sandbox's
GitHub App token is read-only on the app repository. Every write path was refused by GitHub
(`git push` → `403 Permission to … denied`, `POST /git/refs` → `403 Resource not accessible by
integration`), while the same token can write only to `dictationb1/supreme-lamp-lab`. The
established pattern for this lab — produce the verified patch here, publish it from a
credentialed checkout — is what this branch delivers.

Release bundle: [`releases/2026-10-23-v2.4.0/`](../../releases/2026-10-23-v2.4.0/README.md)
(`app/` changed files, `0001-release-v2.4.0.patch`, `v2.4.0.diff`, `apply-release.sh`).

## What the release changes

1. **Credit badge (`#credit`)** — the water-drop SVG (`.c-drop`) is replaced by an animated
   Liquid Glass swan (`.c-swan`): dual white→aqua→mint gradients, specular wing, amber beak,
   a `swan-ripple` ellipse and three continuously running animations (`swanFloat` 3.2 s,
   `swanWing` 2.4 s alternate, `swanRipple` 2.8 s). The 350 ms spring entrance, 5.2 s hold,
   exit, 900 ms gap, hover/touch pause and click toast are unchanged and stay live in Full
   **and** Lite.
2. **Hero headline** — `<span class="hollow">Liquid Glass</span>` and the `.hollow` rule are
   removed; `#homeTitle` (`.liquid-glass-text`) now *is* the material: crystal/prism gradient,
   `background-clip: text`, `-webkit-text-stroke: 1.35px`, cyan shadow, opaque light-theme
   variant.
3. **Material Mixer moved Home → Settings** — `#lgStage` (bubbles, chips, draggable orb,
   Blur/Saturate/Bright sliders with live `--fill`, Clear·Frost·Smoke and
   Auto·Lite 60FPS·Full capsules) renders at the top of `Screens.settings()` under
   "Appearance · Liquid Glass". Home is a single full-width `.lg-hero` (`display: block`) with
   the anatomy stage, the three Bento tiles and Past sessions. New `UI.applyGlassSettings()`
   restores the saved material on boot and on every mixer bind.
4. **Zero-lag pass** — one backdrop shader per surface (nested glass flattened), GPU-promoted
   fixed bars, pre-blurred blobs with `filter: none`, `#grain` still `display: none`, universal
   `translate3d` capsule springs, automatic Lite detection and the 1.2 s frame probe unchanged;
   the low-data engine (embedded dictionary answers, buffered Amy MP3 replay) unchanged.
5. **Release plumbing** — `APP_VERSION = "2.4.0"`, `CONFIG.key = "sdp.v16_swan"`,
   `schema = 16`, `settingsRev = 16` (v15 data migrates in place), `data/*.json` at `ver: 16`.
